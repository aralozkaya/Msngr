# Messenger display pictures

45 original images downloaded from the **Display pictures** section of the
[Windows Wallpaper Wiki's Windows Live Messenger page](https://windowswallpaper.miraheze.org/wiki/Windows_Live_Messenger#Display_pictures).

- MSN / Windows Live Messenger 6.1–8.5: 11 PNGs.
- Windows Live Messenger 2009: 25 PNGs and 5 animated GIFs.
- Windows Live Messenger 2011–2012: 4 additional animated GIFs. These versions also
  reused earlier pictures, as described on the source page.

The source section has no APNG or other animation formats. All nine animations are
the original GIF files, not still posters or wiki thumbnails. Files have not been
resized, recompressed, or converted. Scenes, backgrounds, and other assets from the
page are deliberately excluded.

`catalog.json` records original URLs, file-description pages, source table credits,
byte counts, and SHA-256 hashes. Artwork belongs to its respective copyright
holders; the wiki's text license does not establish an artwork license. Refer to
the individual file pages for provenance and rights information.

To reproduce the download, run `python tools/download_display_pictures.py` from the
repository root. The importer uses Python's standard library.
