The `res/drawable-nodpi/msn_emoticon_*.png` files are the original 19px MSN
Messenger emoticons from https://github.com/bernzrdo/msn-emoticons at commit
`4f987790de5e222c8219d9f35ce5a63520b95e80`.

The upstream repository says the artwork was extracted from Escargot. It does
not currently include a separate license file.
